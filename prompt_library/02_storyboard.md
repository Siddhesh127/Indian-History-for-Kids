# Storyboard Generator

## Purpose

Convert a narration script into a detailed storyboard for image generation.

The storyboard divides the story into visual scenes that will later be converted into AI-generated illustrations.

---

## Input

Replace

{{SCRIPT}}

with the narration generated by master_script.md.

---

## Prompt

Convert the following narration into a storyboard suitable for a YouTube Shorts video.

SCRIPT

{{SCRIPT}}

Requirements

Generate exactly 10 scenes.

For every scene provide:

Scene Number

Scene Description

Camera Angle

Camera Movement

Emotional Tone

Suggested Duration (3–5 seconds)

Scene descriptions should be concise but visually detailed.

The storyboard should flow naturally from one scene to the next.

Avoid repeating similar scenes.

Each scene should introduce a meaningful visual change.

Output only the storyboard.

---

## Example

Scene 1

Shivaji Maharaj stands under house arrest inside Agra Fort.

Camera

Movement

Emotion

Curiosity

Duration

5 seconds
