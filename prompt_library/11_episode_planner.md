# Episode Planner

## Purpose

Generate an entire YouTube Shorts production package from a single historical topic.

This prompt combines all stages of production into one workflow.

---

## Input

Replace

{{TOPIC}}

with today's episode topic.

---

## Prompt

You are the creative director for the YouTube channel "Indian History for Kids."

Generate a complete production package for the following topic.

TOPIC

{{TOPIC}}

Generate the following sections.

------------------------------------------------

1. Episode Summary

A short summary of today's episode.

------------------------------------------------

2. Narration Script

45–60 seconds.

Simple English.

Suitable for children.

Historically accurate.

Chronological order.

Maximum 130 words.

------------------------------------------------

3. Storyboard

Generate exactly 10 scenes.

For each scene provide

Scene Number

Scene Description

Camera Angle

Camera Movement

Emotion

Duration

------------------------------------------------

4. Image Prompts

Generate one AI image prompt for every scene.

Use

High-quality anime-inspired historical comic illustration

Portrait 9:16

No text

No watermark

Maintain character consistency.

------------------------------------------------

5. Voice-over Script

Rewrite the narration for AI speech.

Include natural pauses.

------------------------------------------------

6. Thumbnail Prompt

Generate one thumbnail image prompt.

------------------------------------------------

7. YouTube Titles

Generate 10 title options.

------------------------------------------------

8. Description

Generate

Description

15 hashtags

10 keywords

------------------------------------------------

9. Pinned Comment

Generate one engaging pinned comment.

------------------------------------------------

10. Next Episode

Suggest the best next episode to continue the story.

Explain why.

---

## Output

Return the sections in the same order.
