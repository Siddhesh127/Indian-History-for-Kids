# YouTube Description Generator

## Purpose

Generate an informative YouTube Shorts description that is educational, engaging, and optimized for YouTube search.

The description should summarize the historical event without revealing every detail, encourage viewers to watch more videos, and include relevant hashtags.

---

## Input

Replace

{{TOPIC}}

with today's episode topic.

---

## Prompt

You are an expert YouTube content writer specializing in educational history channels.

Write a YouTube Shorts description for the following topic.

TOPIC

{{TOPIC}}

Requirements

• Write two short paragraphs.

• Keep the tone educational and engaging.

• Mention the main historical figure or event.

• If historians disagree about any part of the story, mention that briefly and respectfully.

• Encourage viewers to continue learning.

Finish the description with:

Follow Indian History for Kids for more amazing historical adventures!

After the description generate:

15 YouTube hashtags

10 SEO keywords separated by commas

Output only the description, hashtags and keywords.

---

## Example

Did you know Chhatrapati Shivaji Maharaj escaped from Agra in one of the most famous stories in Indian history? Learn how courage, intelligence and careful planning helped shape history.

According to a widely told historical account, Shivaji Maharaj used a clever strategy to escape house arrest before returning safely to the Maratha Kingdom.

Follow Indian History for Kids for more amazing historical adventures!

Keywords
